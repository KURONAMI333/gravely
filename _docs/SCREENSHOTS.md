# Screenshots / GIF 撮影シナリオ

Modrinth / CurseForge / README に貼る画像の撮影ガイド。henkelmax 方式（機能 × 画像のペア配置）に従う。

## 撮影前準備

- 解像度: **1920x1080** で撮影、必要なら後で 1280x720 にリサイズ
- HUD: F1 で消すか、必要な部分だけ残す
- F3+H で advanced tooltips ON（エンチャント詳細を見せたい時）
- 周囲の景観を整える: 草原・砂漠・森・洞窟など多様性
- リソースパック: バニラ or デフォルトに近いもの (見やすさ優先)
- 時間帯: 昼間ベース、雰囲気重視なら夕暮れ・夜
- ShareX または Windows Game Bar (`Win+G`) で録画/スクショ

## 必須スクショ (公開時に最低限欲しい)

### 1. ヒーロー画像 (バナー、Modrinth ページの最初に出す)
- 場面: 草原で墓ブロックが立ってるシンプルな構図
- 構図: 中央に墓、背景に空、左右に余白。Modrinth バナーは横長 (1920x300 程度)

### 2. 墓ブロックのアップ
- 場面: クリエイティブで設置した墓を斜め45度から
- ポイント: テクスチャの質感がよく見える

### 3. 死亡 → 墓生成
- GIF: プレイヤーが死亡 → 墓が立つ瞬間 → 弔いの鐘の余韻 (5秒程度)
- 死亡前にインベントリ満載状態 (剣・防具・食料) でやると保管されたことが伝わる

### 4. 右クリックで回収
- GIF: 墓に右クリック → 紫の演出 → アイテム復活 → 墓消滅 (3秒)
- アクションバーに「アイテムをすべて回収しました」が出てるとなお良い

### 5. JourneyMap waypoint
- 場面: ミニマップに紫の "の墓" waypoint が表示されてる
- 構図: 画面右上ミニマップ + プレイヤー視点
- 別バージョンで Worldmap (Mキー) フルスクリーンも

### 6. Curios slot 連携
- 場面: Curios のアクセサリ装備した状態 (Artifacts 等のリング/アミュレット)
- GIF: 死亡 → 墓に保管 → 回収すると Curios slot に自動再装着

### 7. ソウルバウンドエンチャ
- 場面1: ソウルバウンド付きエンチャ本のホバー (説明テキストが見える)
- 場面2: ソウルバウンド付き剣を持って死亡 → リスポーン後インベントリに残ってる
